# 高森雨 · 日子有趣一点

个人生活博客的首页原型。使用提供的林间人像照片，结合全屏主视觉、森林绿与奶油白配色，以及活泼的中文文案。

## 本地查看

直接打开 `index.html` 即可查看，图片、样式与交互均无需联网。

安装了 Node.js 时，可在项目目录运行：

```sh
npm run dev
```

访问终端显示的 `http://127.0.0.1:4173`。预览期间修改首页或素材会自动刷新。无需安装依赖。

## 首页内容

- 首屏：主照片、个人名字、标题、相册与关于我的入口。
- 生活切片：两张林间写真，点击放大后可手动切换。
- 快乐相册：19 岁生日、湖州弁山出游、贴纸自拍、聚餐、Cosplay 与游戏视频；支持按主题筛选。
- 碎碎念：三段为首页起草的示意手记，点击标题可展开。
- 关于我：个人介绍与回到顶部。

滚动时包含主视觉的轻微视差、内容渐入、照片上下错落、装饰文字随滚动横移与页顶阅读进度。由访客手动滚动，页面不自动向下移动。首屏左下角可以暂停动态，并记住选择；默认遵循系统的减少动态设置。

相册大图支持上一张、下一张、左右方向键和 Escape 关闭；单张图片不显示切换按钮。游戏视频可点击画面中央的“播放这 8 秒”按钮，也支持浏览器原生控件，结束后可重播。仅预加载视频信息，不自动播放；筛选隐藏视频时会暂停。加载失败会显示重试入口，并提供“单独打开视频”链接。

正式告别与版权信息之后，继续手动往下滚动，可以看到片尾彩蛋：“对了，我有一个爱而不得的男神，哈哈哈”。

## 后续换照片与文案

- 图片放在 `assets/`，照片原样保存，展示裁切仅由页面样式完成。最初的首页封面是 `assets/senyu-forest.jpg`。
- 新增九张原图：`forest-dress-01/02.jpg`、`birthday-01/02.jpg`、`cosplay-01/02.jpg`、`benshan-swing.jpg`、`sticker-day.jpg` 和 `dinner.jpg`。
- 游戏视频 `game-eight-seconds.mp4` 已转换成浏览器常用的 H.264 / AAC 格式，时长约 8 秒，封面 `game-poster.jpg` 来自原视频。
- 首页文案与相册结构在 `index.html`。
- 样式、手机适配在 `assets/style.css`。
- 滚动效果、移动导航和照片放大在 `assets/main.js`。

目前所有导航均跳转到首页的对应区域。后续可以扩展独立相册、文章详情及分类页。

朋友圈截图只用来核对说明，没有作为公开页面图片：生日日期为 2026-08-06（19 岁）；出游记录为 05.04、湖州弁山拾点伴，未推断年份；未标注时间的素材不添加日期。游戏标题与“一次性三个”来自提供的截图，其余配文为这版首页新写的文案。

## 静态发布

在线访问：<https://gaosenyu-life-journal.jollypetal515.chatgpt.site>。

源码仓库：<https://gitee.com/dreams-of-the-cool-city-past/gsy_person_web>。网页通过 Sites 独立发布，任何人都可以访问。

首页和资源均使用相对路径，支持部署到域名根目录或仓库子目录。

需要单独的发布目录时，运行：

```sh
npm run build
```

生成的 `dist/` 包含可发布的首页与资源。`.publish/` 是独立发布所用的本地副本，不提交到 Gitee。
